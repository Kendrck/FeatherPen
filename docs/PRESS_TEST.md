# GB/T 8567 V1.0.0 特权UID压测功能规范
## 一、权限判定核心规则
1. 压测功能准入唯一依据：账号UID存在PRIVILEGE_UID白名单["000000","111111","222222","333333","444444","555555","666666","777777","888888","999999"]
2. 仅白名单账号拥有压测入口与接口调用权限
3. 仅Lv9等级但不在白名单、Lv0游客、Lv1~Lv8标准账号，全部禁止访问压测功能
4. 三层拦截机制：前端控件隐藏 + 接口403拦截 + 后端UID二次校验，无法绕过
## 二、压测开关控制逻辑
1. 前端页面路径：web/pages/member.html、web/pages/model_setting.html
2. 页面渲染：登录UID属于白名单才展示压测开关，其余账号永久隐藏
3. 配置存储节点：member_config.json -> cloud_privilege.pressure_mode_unlock
4. 生命周期：程序重启自动重置为false，开关状态不持久化存储
## 三、压测模式生效权限
1. 章节、大纲、人物、时间线生成上限无999999限制
2. 关闭Token流量限流统计机制
3. 批量AI生成移除休眠间隔，全速调度推理任务
4. 开放全部硬件、Token、生成回放监控面板
5. 压测开启同步生效白名单自带积分豁免权限
## 四、关闭触发条件
1. 程序完整重启自动关闭压测
2. 用户手动切换开关立即恢复常规限流与章节上限
3. 切换非白名单账号登录自动关闭
## 五、开发约束规范
1. 压测仅本地离线功能，无云端算力、云端压测接口
2. 新增/修改压测接口、函数，同步更新API.md、API_MODULE_SPEC.md
3. V1.0不实现任何云端压测相关代码
