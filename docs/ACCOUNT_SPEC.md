# FeatherPen/docs/ACCOUNT_SPEC.md
# GB/T 8567 V1.0.0 离线账号三层校验国标规范
## 一、账号基础硬性约束
### 普通注册账号（非豁免UID）
1. 字符长度6~20位，超出直接拦截
2. 合法字符：大小写字母、数字、下划线_、减号-、英文点.
3. 邮箱格式仅允许单个@，匹配专用邮箱正则
4. 密码最低6位，推荐字母数字混合高强度组合

### 豁免校验固定UID（跳过通用账号正则）
1. Lv0离线游客固定UID：127001
2. Lv1~Lv9六级特权UID集合：["000000","111111","222222","333333","444444","555555","666666","777777","888888","999999"]
3. 特权账号统一密码：passwd，全局固定积分999999999

## 二、三层全链路安全校验（强制全链路执行）
1. 前端层：index.html/login页面JS输入失焦、登录按钮实时校验，标准化弹窗提示
2. 后端层：src/account/local_login.py强制二次正则校验，前端篡改无法绕过校验逻辑
3. 数据库底层：local_user表uid唯一主键、bind_email/bind_phone独立唯一索引，杜绝重复绑定

## 三、Lv0~Lv9会员分级权限（数据源member_config.json）
Lv0 无名（127001游客）：低章节上限，完整AI监控，豁免账号格式校验
Lv1~Lv8：逐级开放章节生成、世界观校验、监控面板权限
Lv9 不朽特权：无章节数量上限，支持积分豁免开关、压测功能解锁

## 四、永久废弃账号相关功能
1. 8位数字云端账号、YesApi云端对接整套规则全部删除
2. 硬件SN、机器UUID自动登录逻辑永久移除
3. 云端注册、充值、积分商城仅V2.0规划，V1.0无任何业务代码

## 五、常量对齐强制规则
前端api_client.js必须完整复制后端local_login.py的OFFLINE_GUEST_UID、PRIVILEGE_UID_LIST常量，禁止前端单独自定义一套
