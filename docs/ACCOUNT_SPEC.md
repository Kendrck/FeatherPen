# FeatherPen/docs/ACCOUNT_SPEC.md
# GB/T 8567 V1.0.0 离线账号三层校验国标规范
## 一、账号基础硬性约束
### 普通注册账号（非豁免UID）
1. 字符长度区间6~20位，超出拦截
2. 合法字符集：大小写字母、数字、下划线_、减号-、英文句点.
3. 邮箱仅允许单个@符号，配套专用正则校验
4. 密码最低6位，推荐字母数字混合高强度组合
### 豁免校验固定UID
1. Lv0离线游客固定UID：127001
2. 特权UID白名单（积分豁免、压测权限唯一判定依据）：["000000","111111","222222","333333","444444","555555","666666","777777","888888","999999"]
3. 全部特权账号统一密码：passwd，初始积分固定999999999
## 二、三层全链路安全校验（强制全流程执行）
1. 前端校验：登录页面输入失焦、提交按钮实时正则校验，标准化弹窗提示
2. 后端校验：src/account/local_login.py二次强校验，前端篡改无法绕过
3. 数据库约束：local_user表uid唯一主键，bind_email、bind_phone独立唯一索引，杜绝重复绑定
## 三、Lv0~Lv9会员分级权限规则
Lv0 无名游客(UID=127001)：章节生成上限低，开放完整监控，豁免账号格式校验
Lv1~Lv8 标准会员：逐级开放章节、世界观校验、监控面板访问权限
Lv9 不朽会员：仅扩容章节生成上限，**无积分豁免、无压测解锁权限**；积分豁免、压测功能仅特权UID白名单账号可启用
## 四、永久废弃业务功能
1. 8位云端账号、YesApi对接、云端登录整套规则全部移除
2. 硬件SN、设备UUID自动登录逻辑永久删除
3. 云端充值、积分商城仅V2.0规划，V1.0无任何落地代码
## 五、常量对齐强制规范
前端web/assets/js/api_client.js必须完整复制后端local_login.py内OFFLINE_GUEST_UID、PRIVILEGE_UID_LIST常量；单元测试强制校验前后端常量完全一致，规避权限绕过漏洞
