# FeatherPen V1.0.0 离线账号标准化规范 GB/T 8567
## 1. 账号基础硬性约束
### 1.1 普通账号（非豁免UID）
1. 长度：6~20字符，超出直接拦截
2. 合法字符：大小写字母、数字、下划线_、减号-、英文点.；禁止中文、空格、#$%^&*等特殊符号
3. 邮箱账号：仅允许单个@符号，匹配专用邮箱正则
4. 密码：最低6位，推荐8位字母数字混合高强度组合

### 1.2 豁免校验UID（跳过通用用户名正则）
1. Lv0离线游客固定UID：127001
2. Lv9特权6位数字UID集合：000000、111111、222222、333333、444444、555555、666666、777777、888888、999999
3. 特权账号统一密码：passwd，积分固定999999999

## 2. 三层校验安全机制（强制全链路执行）
1. 前端层：login.html/index.html JS实时校验，失焦/点击登录拦截，弹窗标准化错误提示
2. 后端层：src/account/local_login.py 强制二次正则校验，篡改前端JS无法绕过
3. 数据库层：local_user表uid主键唯一、bind_email/bind_phone独立唯一索引，底层拦截重复绑定

## 3. Lv0~Lv9会员权限分级（取自member_config.json）
Lv0 无名（游客127001）：生成上限低，开放完整监控数据，豁免账号格式校验
Lv1~Lv8 递增开放生成上限、监控权限
Lv9 不朽特权：无生成数量上限，支持积分豁免开关、压测功能解锁

## 4. 废弃功能说明
1. 硬件采集自动登录：永久删除，无任何硬件标识关联账号逻辑
2. 云端账号、在线注册、充值商城：V1.0仅预留配置字段，不编码实现
