# FeatherPen/docs/DEVELOP.md
# GB/T 8567 V1.0.0 本地开发调试国标规范
## 一、开发前置环境要求
Python >=3.10；内存≥4G；纯本地离线开发，无需云端服务
依赖自动安装：执行init_env.py创建虚拟环境、安装requirements.txt全部依赖
## 二、标准开发启动流程
1. 切换项目根目录
2. 初始化环境：python init_env.py
   自动生成data/runtime四级目录、写入6554/1234标准端口配置
3. 启动程序：python main.py
   自动初始化SQLite、创建10组特权UID白名单账号、启动FastAPI与客户端窗口
## 三、开发硬性约束
1. 禁止修改一、二级目录名称/结构，仅新增、修改三级文件
2. 代码仅保留国标业务注释，删除print调试、迭代草稿、TODO备注
3. 端口统一通过config_loader读取，禁止硬编码6554、1234
4. 账号权限严格遵循ACCOUNT_SPEC：仅PRIVILEGE_UID白名单拥有积分、压测特权，Lv9仅扩容章节上限
5. 文件增删、接口、端口修改必须同步更新STRUCTURE.md、API_MODULE_SPEC.md两份归档文档
6. 废弃函数、目录统一录入两份文档黑名单，全项目清理残留调用
## 四、故障排查标准方案
1. 端口占用：查看控制台输出实际Web端口；LLM 1234需手动结束占用进程
2. 数据库丢失：执行init_db自动重建数据表、预置特权账号
3. 配置文件丢失：init_env自动生成国标端口配置
4. 导入报错：统一使用load_global_config、get_account_info标准函数
## 五、单元测试规范
1. 测试目录与src业务模块一一对应
2. 仅编写本地离线用例，不编写云端相关测试
3. 执行测试前重置运行环境
## 六、交付验收标准
1. 无云端、8位UID残留文字，无调试、草稿注释
2. STRUCTURE.md、API_MODULE_SPEC目录树、变更记录同步更新
3. 端口、权限逻辑与全套规范文档完全一致
4. 一键初始化+启动无报错
