# GB/T 8567 Lv9账号压测解锁规范
## 一、压测功能前置条件
仅Lv9六级特权账号（000000/999999）可解锁压测模式
普通Lv1~Lv8、127001游客无压测权限

## 二、压测开关控制位置
会员面板model_setting页面，Lv9登录自动展示压测解锁控件
底层配置节点：member_config.json → cloud_privilege.pressure_mode_unlock

## 三、压测模式生效权限
1. 章节生成上限999999无限制
2. 关闭Token消耗统计限流
3. 批量生成无间隔休眠等待
4. 完整硬件/Token监控面板全部开放

## 四、关闭规则
重启程序自动重置压测开关为false，不持久化开启状态
## 五、约束规范
压测仅本地离线功能，无云端压测接口
禁止Lv0-Lv8账号绕过权限开启压测，后端接口二次拦截
