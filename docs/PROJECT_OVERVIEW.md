# GB/T 8567 V1.0.0 项目离线隐私整体规范
## 一、项目定位
纯本地离线AI小说创作工具，全部网络通信仅127.0.0.1本地回环，无外网请求、云端存储、云端算力调用；账号、小说工程全部本地持久化，不上传任何第三方服务器
## 二、核心技术栈
Python3.10+、FastAPI、PyWebView、原生HTML/CSS/JS、SQLite本地数据库
永久移除Electron、PyQt6图形框架，无相关业务代码、打包流程
## 三、账号体系核心规则
1. Lv0游客固定UID=127001，豁免账号格式校验
2. 特权UID白名单：["000000","111111","222222","333333","444444","555555","666666","777777","888888","999999"]
3. 权限分界线：Lv0~Lv9会员等级仅控制章节、监控生成上限；积分豁免、无上限批量生成、压测功能仅特权UID白名单账号拥有，Lv9等级无专属特权
## 四、端口通信标准
1. Web后台端口6554：端口占用自动遍历分配空闲端口
2. LLM推理端口1234：固定配置，不自动切换
3. 所有服务仅监听本地回环，禁止0.0.0.0公网开放
## 五、数据存储规则
小说工程、账号库存放本地data目录，无云端同步、上传、下载逻辑
## 六、V1.0永久废弃业务
8位数字云端账号、YesApi对接、云端充值积分商城、硬件SN自动登录全部移除，仅V2.0规划，V1.0无落地代码
## 七、版本迭代说明
云端协作、在线同步功能仅V2.0迭代计划，当前V1.0版本无相关编码实现
