# FeatherPen/docs/dev/UI_Compatibility_Spec.md
# GB/T 8567 V1.0.0 Web前端跨平台兼容强制规范
## 一、基础架构约束
1. 废弃PyQt6/Electron双桌面框架，统一采用纯HTML+PyWebView桌面壳
2. 一套前端源码全平台复用，禁止Windows/macOS/Linux分支UI代码
3. 页面交互、校验逻辑前后端100对齐，无平台差异化规则

## 二、网络与端口统一规范
全平台固定绑定127.0.0.1，Web端口默认6554，LLM推理1234，端口占用自动分配空闲端口，各平台逻辑完全一致

## 三、账号体系跨平台统一
127001游客、000000~999999六位特权账号规则全平台相同，前端校验JS常量与后端local_login.py完全复制，禁止单独自定义正则

## 四、降级适配规则
1. 硬件监控：Android/小程序自动隐藏GPU/CPU面板，保留基础生成功能
2. 悬浮监控FloatWidget仅桌面端启用，Web/移动端禁用置顶拖拽
3. i18n多语言全平台资源统一，缺失语言自动回退简体中文

## 五、UI性能硬性约束
1. 闲置页面CPU占用≤2%，单组件内存上限10MB
2. 定时器生命周期绑定页面销毁，杜绝内存泄漏
3. 无后台持续轮询冗余请求，按配置间隔刷新

## 六、禁止差异化开发内容
1. 禁止针对单一系统编写专属页面、校验逻辑
2. 禁止硬件采集、注册表读取Windows独有逻辑
3. 不新增云端登录、8位账号平台分支代码
